# TV 侧栏与纵向推荐

首页使用固定左侧导航与右侧浏览区。左侧包含首页、推荐、搜索、收藏、历史、设置和账号；标准视口按钮高 48dp，小高度视口高 40dp。右侧保留固定焦点介绍，内容区沿纵向滚动。

继续追番、热门、今日更新和类型入口位于推荐之前。推荐使用标准视口四列、小视口三列网格；接近已加载内容末尾时读取后续页。左侧推荐入口直接定位推荐网格，首页入口定位首个首页内容。网格方向键上下换行、左右换列；最左列按左回推荐导航，导航按右恢复内容焦点。进入详情返回时恢复业务条目及滚动位置。失败重试、空内容刷新、分页末尾和内容保护保持可操作。

背景使用当前焦点番剧封面、深色水平与垂直渐变、蓝紫色柔和光晕。标题和卡片区域保持足够遮罩。受内容偏好保护的条目不能通过全屏背景泄露图片；缺图、加载失败和空内容使用纯渐变背景。图片不自动轮播、不播放视频、不使用模糊滤镜或焦点缩放。

验收使用 960×540dp 与 720×405dp，验证侧栏完整可见、推荐下翻、分页、最后一行、重试、返回焦点与背景内容保护；优化 APK 使用真实接口完成遥控器截图验收。沿用当前 TV Preview 包名与签名，发布独立版本附件。
