# Android TV 应用导航框架

电视端非播放页面共用固定左侧导航，右侧为当前 Tab 或详情内容。导航入口为首页、推荐、搜索、收藏、历史、设置和账号；首页与推荐定位同一首页的不同区域。视频播放器使用全屏；筛选和确认弹窗使用独立模态焦点域。

顶层 Tab 各自保留搜索条件、滚动位置、ViewModel 和子页面返回路径，重复选择同一入口不会累积重复页面。返回先退出详情，再从顶层页面回到首页；首页返回交给系统。

侧栏上下选择、确认切换、右键恢复当前页面的内容焦点。内容左边界可回到对应侧栏入口；设置内容先返回内部分类。文本编辑时左右键控制光标，弹窗显示时焦点停留在弹窗。页面与侧栏共用当前页面的焦点状态，异步数据更新不能抢走侧栏焦点。

标准视口960×540使用112dp侧栏，紧凑720×405使用96dp侧栏。搜索工具栏、设置分类和登录输入区依据剩余宽度布局。内容保护和原有分页约束保持有效。

验证覆盖导航状态、Tab循环切换、筛选状态、焦点往返、详情返回、播放器全屏、两种视口的内容边界以及APK安装运行。
