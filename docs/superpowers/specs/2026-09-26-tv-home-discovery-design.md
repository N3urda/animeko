# 电视首页内容浏览

首页面向方向键遥控器，使用现有番剧服务的数据。Netflix 电视首页的顶部快捷入口、内容介绍和主题分区是交互参考：https://about.netflix.com/en/news/unveiling-our-innovative-new-tv-experience 。

## 布局与行为

- 单行品牌与导航：搜索、收藏、历史、设置、账号、推荐。品牌和当前页面共享一行，导航保持可达。
- 焦点预览：固定高度，展示选中番剧名称、来源、真实评分、年份、标签和两行简介。请求失败不影响打开详情；快速移动只读取停留条目，详情按 ID 缓存并限制容量。不播放背景视频。
- 紧凑横卡：封面保留 2:3 比例，旁边显示标题和栏目语义。960×540dp 的首屏能完整显示热门和推荐两排；小屏至少完整显示当前卡片。
- 内容分区：继续追番（存在时优先）、热门番剧、推荐番剧、今日更新、按类型找番。今日更新来自已有新番时间表，按当地日期筛选、按条目去重，展示集数和播出时间；空、加载、失败和重试都有明确状态。
- 类型入口使用规范标签，进入现有搜索并带入该标签，返回恢复原分类焦点。
- 遥控器上下跨栏目、左右浏览同栏、确认打开详情；返回按条目 ID 恢复焦点。预览和网络响应不自动移动焦点。推荐快捷入口、分页与重试保持可用。
- 内容偏好为隐藏时不展示受限条目；遮盖时预览也不泄露标题、简介或图片。

## 验证

使用合成 Compose 遥控器输入验证双排密度、焦点预览、类型路由、返回、加载和失败；数据测试覆盖请求取消、缓存、时间表去重。运行现有 TV 回归测试。Android TV 模拟器检查 960×540dp 和 720×405dp 的真实网络内容、截图和崩溃日志。
